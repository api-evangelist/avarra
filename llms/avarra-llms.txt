# Avarra

> Avarra is an AI-powered sales training and enablement platform operated by Ramp Systems, Inc. It turns real sales conversations into AI-avatar role-play simulations delivered over Zoom, coaches reps with automated feedback, certifies them against a playbook, and reports ramp and performance analytics. Avarra runs a production API at https://api.avarra.ai, but publishes no OpenAPI, no developer documentation and no SDKs — the entire /v1 surface is closed behind OAuth 2.0 client-credentials access granted through a commercial relationship.

This file was GENERATED by API Evangelist from probed evidence, not published by Avarra. Avarra serves no /llms.txt of its own (404 on www.avarra.ai, app.avarra.ai and app.ramp.systems). Everything below is either a document fetched from an Avarra host or an observation recorded with the status code it returned.

## What an agent can actually do here

Nothing, without credentials. There is no public read surface, no free tier, no sandbox and no self-serve signup. The only anonymous endpoints are a health check, the OAuth authorization-server metadata and the JWKS. Access begins at the demo request form.

## API

- [Avarra API v1](https://api.avarra.ai): production API host, AWS ALB. All paths under `/v1/` return `401 {"error":"unauthorized","message":"missing or invalid authorization header"}` without a bearer token. Unrouted paths are refused at the load balancer with a plain-text `403 Access denied`.
- [Health check](https://api.avarra.ai/health): anonymous, returns `200 {"status":"ok"}`.
- [Token endpoint](https://api.avarra.ai/oauth/token): POST only, `client_credentials` grant, `client_secret_basic` or `client_secret_post`.
- [Introspection endpoint](https://api.avarra.ai/oauth/introspect): POST only, RFC 7662.

## Machine-readable documents Avarra publishes

- [OAuth 2.0 Authorization Server Metadata](https://api.avarra.ai/.well-known/oauth-authorization-server): RFC 8414, HTTP 200, `application/json`. Declares issuer, token endpoint, introspection endpoint, JWKS URI, `client_credentials` grant and the two client-authentication methods. No `scopes_supported`.
- [JWKS](https://api.avarra.ai/.well-known/jwks.json): RFC 7517, HTTP 200. One RSA key, `kid` 5d22a766-d768-41e0-bbfc-ac0aa04afe90.

These two documents are the whole of Avarra's machine-readable surface.
